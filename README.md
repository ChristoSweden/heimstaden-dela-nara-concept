# Dela nära — Heimstaden concept demo

A standalone, clickable concept for a verified local reuse marketplace for Heimstaden tenants in Värnamo.

## Important

This is an independent concept demo. It is not an official Heimstaden service and has not been approved or commissioned by Heimstaden. All listings, people, interactions and pilot targets are fictional examples.

Only contract-verified properties should be available in a real pilot. No payment, public messaging, external users or backend data collection is included in this demo.

## Run locally

Open `index.html` in a modern browser.

## Brand alignment

- Typography: Figtree, matching Heimstaden's live Swedish website.
- Core palette: Heimstaden orange `#ff5000`, charcoal `#333132`, white and warm off-white `#f9f7f6`.
- UI character: white navigation, light-weight body copy, 600-weight headings and rounded service controls.
